# GAMMA IMAGE PROMPTS
## Derived Build · canonical source for diagram composition · 42 slides

**Never pasted into Gamma as a whole.** Work slide by slide: paste the **Gamma Image Prompt** into that card's image or diagram field, then apply the **Diagram Prompt** constraints if the result restructures anything.

**Geometry is meaning.** Where a prompt fixes a count, an order, an axis, a proportion or an emptiness, that constraint is the argument. Gamma may restyle freely; it may not restructure. **No diagram meaning may be inferred by Gamma** — a result that comes back with a different number of tiers, a resolved ambiguity, or a filled void has produced a different claim and must be regenerated.

**Node and axis labels in the Infographic Prompt are not slide text.** The slide text was reduced under WET-EXEC-011; these labels exist only here, and this file is their canonical home.

No people, no photography, no robots, no brains, no circuit boards, no servers, no handshakes, no icons unless specified. Structure and typography only.
