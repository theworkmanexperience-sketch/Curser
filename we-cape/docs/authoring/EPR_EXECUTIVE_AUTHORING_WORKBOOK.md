## 1 · The vocabulary

`dramatic_intensity` accepts **exactly these five tokens**. No sixth value is valid. No blend,
range, or arrow is valid.

```
LOW          MODERATE          HIGH          ELEVATED          CLIMACTIC
```

The descriptors below are **transcribed from EPR-001**, where they were already ratified.
They are the registry's own words, not the platform's gloss:

| token | ratified descriptors |
|---|---|
| `LOW` | Reflective · Observational |
| `MODERATE` | Engaged · Conversational |
| `HIGH` | Purposeful · Energetic |
| `ELEVATED` | Commanding · Emotionally Significant |
| `CLIMACTIC` | Defining · Irreversible |

### 1.1 The scale is **ORDERED** — ratified 2026-08-28

**Executive Ruling Q11 — Ordered Categorical Dramatic Intensity Standard.** The scale is an
**ordered categorical hierarchy describing narrative significance within the documentary.**

```
LOW  →  MODERATE  →  HIGH  →  ELEVATED  →  CLIMACTIC
```

| the ruling's own terms |
|---|
| The categories are **ordinal**. |
| They are **not numerical**. |
| They shall **never be averaged, interpolated, scored, normalized, or smoothed**. |
| **Advancement between categories is by explicit Executive declaration only.** |

**What this changes for you as you answer.** The tokens now rank, so the six you choose across
six beats also describe a **progression**, not just six independent labels. **`ELEVATED` outranks
`HIGH`** — which reads oddly against the descriptors *Purposeful/Energetic* versus
*Commanding/Emotionally Significant* until you hold the ruling's own words in mind: **this is a
significance scale, not an energy scale.** A quiet moment can outrank a loud one.

> ### `OQ-1` — **RESOLVED 2026-08-28**
>
> > *Comparing discrete steps (e.g., checking if the next beat is higher or lower for a handoff)
> > is a legitimate transition check, but algorithmic trend-fitting or curve-smoothing remains
> > barred by Invariant B.*
>
> **Nothing changes about how you answer.** You choose one token per beat, as before. The ruling
> governs what a downstream consumer may do with the six tokens once they exist.

   reworded. `EPR-05`'s arrow survived two transcriptions this way.
2. `epr_validate.py` re-runs V-1…V-6 — **structure only.** `V-6` checks that any
   `dramatic_intensity` is one of the five ratified tokens. **That is a vocabulary check. It
   cannot tell whether the token you chose is right, and nothing in this platform can.**
3. `EPR-001`'s `registry_version` increments and the file returns to you for **formal
   ratification.**
4. **Only after that ratification** does Order §4 release the `gen_artifacts.py` RUN_ID lock.
   Until then: no regeneration, no registry population, no Conductor Score.

**Blank fields stay blank.** `missing_data_policy: propagate_unknown` — an unanswered question
propagates as unknown and is never defaulted, in this round or any later one.
